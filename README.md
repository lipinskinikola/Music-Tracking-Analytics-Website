Music Tracking & Analytics Website 

A web-based music tracking and analytics platform developed as a university project. The website allows users to input, organise and view information about music, including albums, artists, songs and monthly listener statistics. 

Overview 

The project focuses on creating a user-friendly interface for managing and displaying music-related data. Users can enter information about different artists, albums and songs, with the website organising and presenting the information in a structured format. 

Features 

Artist Tracking: Input and organise information about music artists. 

Album Management: Record and display album information. 

Song Tracking: Add and manage individual songs. 

Listener Analytics: Record and display monthly listener statistics. 

User-Friendly Interface: Navigate and interact with music-related information through an organised website layout. 

Data Management: Input, store and display user-provided music data. 

Technologies Used 

HTML – Website structure and content. 

CSS – Styling and visual presentation. 

JavaScript – Interactive functionality and data handling. 

Key Development Areas 

Developed interactive website functionality using JavaScript. 

Designed and implemented the website structure using HTML and CSS. 

Created functionality for users to input and display music-related information. 

Applied data management concepts to organise and present user-entered information. 



Project Context 

Developed as part of a university project to apply practical web development skills, focusing on front-end development, JavaScript functionality and structured data presentation.
